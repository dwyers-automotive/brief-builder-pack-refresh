# Brief Builder - Knowledge Pack monthly refresh (option A, 14/11/2026)

The 8 Knowledge Pack files are regenerated by AVA/Riley in a Claude session (the judgement step).
These scripts do everything deterministic afterwards. They are Windows PowerShell 5.1 and run on Ant's laptop,
because the email and heartbeat steps need the internal network and the vault. Paths are built from `$env:USERPROFILE`.

| File | What it does |
|---|---|
| `Invoke-PackRefresh.ps1` | The orchestrator. It checks that the 8 files are present, that 00 and 04 carry today's date, and that sanitisation passes. It then writes the diff against the newest `_Archive` folder to `Output\_Refresh Work\<date>\change_summary.md`, emails Ant from ava@ (draft, then GET-verify, then send) with the change summary and the upload checklist, and writes the `BriefBuilder_PackRefresh` heartbeat. It stops at the first failure and prints True/False. `-NoSend` and `-NoHeartbeat` are for testing; `-SnapshotDate dd/mm/yyyy` is for when it runs on a later day than the regeneration. |
| `Test-PackSanitisation.ps1` | The sanitisation gate. It scans every `.md` in a folder and reports `file:line:rule:snippet`, masking possible secrets. Exit 0 = clean, 1 = hits, 2 = could not run. |
| `Sanitisation-Exclusions.txt` | Names and phrases tied to HR, customer, personal and confidential matters. **Gitignored: it holds names.** It lives only in OneDrive. Add a line whenever a new matter of that kind is logged. |
| `Sanitisation-Allow.txt` | Known-safe entries: the public website hosts (`host:`) and exact phrases. Keep it minimal. |
| `Compare-PackVersions.ps1` | The "what changed" diff. It lists added/removed/status-changed projects (04), added/removed roster names (03) and added/removed lessons (06), with changed yes/no and line counts for each file. |
| `Register-BriefBuilderHeartbeat.sql` | Idempotent. It creates or updates the IntegrationControl row with MonitorEnabled 1, MaxAge 50,400 min (35 days), All days and the whole day. It runs through `Invoke-GrantFmtIntegration.ps1`. |
| `New-PackRefreshReminder.ps1` | Creates one recurring To Do task in Ant's default list, due on the first Monday of each month from 07/12/2026. Idempotent. |
| `Run-BriefBuilderSetup-20261114.ps1` | A one-off setup script. It runs a pre-flight check, a dry check, the SQL registration, the reminder, then the first real refresh. |

## Monthly runbook
1. On the first Monday, the To Do reminder fires. Tell AVA: "AVA, refresh Brief Builder pack".
2. AVA archives the current pack to `Knowledge Pack\_Archive\<its snapshot date yyyy-MM-dd>\`, then regenerates the 8 files dated today.
3. On the laptop, run: `powershell -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\OneDrive\PKA_Claude\Projects\Brief Builder\Scripts\Invoke-PackRefresh.ps1"`
4. If it prints False, read `Output\_Refresh Work\<date>\refresh.log` (and `sanitisation_report.txt`) and hand them to AVA to fix and re-run.
5. If it prints True, open the email and follow its upload checklist: claude.ai, then the Brief Builder Project, then Project knowledge. Delete the old 8 files, upload the new 8 (not `_Archive`), then start a test brief.
